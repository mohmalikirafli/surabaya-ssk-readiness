# Surabaya SSK Implementation Dashboard

An interactive bilingual data story on the implementation readiness of **Sekolah Siaga Kependudukan (SSK)** across Surabaya.

## Live website

**[Open the interactive dashboard](https://mohmalikirafli.github.io/surabaya-ssk-readiness/)**

## Project overview

This portfolio project translates collective fieldwork at DP3APPKB Kota Surabaya into a clear implementation story. The source assessment covered 166 junior and senior secondary schools. The dashboard highlights:

- citywide distribution of Paripurna and Basic categories;
- a 43-school deep dive for South Surabaya;
- implementation indicators and observed barriers;
- the relationship between participation in SSK socialisation and possession of a principal's SSK decree;
- actionable priorities: advocacy, socialisation, training, and mentoring.

## Methods

The underlying team assessment combined direct observation, interviews, document checks, data recapitulation, descriptive mapping, and chi-square analysis. Participation in SSK socialisation was associated with possession of a principal's SSK decree (continuity-corrected χ² = 7.378; p = 0.007; n = 166). This result should be interpreted as an association, not causality.

## Data note

The citywide regional panel describes 21 schools classified as Paripurna or Basic. The South Surabaya panel is a separate detailed breakdown of 43 schools and uses registration, willingness, and implementation categories. Counts across these panels should not be added.
